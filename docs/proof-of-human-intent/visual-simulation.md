# Visual Simulation

**Experience [dynamic visual cryptography](/proof-of-human-intent/dynamic-visual-cryptography) in action** through an intent validation simulation.

## 1. 🔻 Choose the device you're currently using

- [**Desktop simulation**](https://simu.interstellar.gg/3F60)
- [**Mobile simulation**](https://simu.interstellar.gg/3F60M)

## 2. Press "Ok"

You can leave the 'participant' field empty

![Visual Simulation Box](/img/Visual_Simulation_Box.png)

## 3. 🖼️ Take a screenshot

## 4. 🔬 Look at the screenshot

:::note
On the **live screen**, you see the intent and one-time code. In the **screenshot**, that information is gone.
:::

:::info
Your **eyes and brain retain a visual impression for about 1/30 of a second**. Interstellar uses that persistence of vision to display frames at 60–120 fps that only humans can contextually decode. See the [threat model](/proof-of-human-intent/threat-model) for what this stops.
:::
