# Sybil Resistance

**Intent validations** not only protect users against attacks, but also **act as a sybil resistance mechanism** — if you want to send a transaction / add or remove backup items / claim your recovery / receive airdrop... — this intent-based authentication makes sure that **only a real human can validate a given operation**.
