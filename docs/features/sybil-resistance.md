# Sybil Resistance

**Proof of Human Intent** not only protects users against attacks, but also **acts as a sybil resistance mechanism**

- If you want to: send a transaction/initiate agent operation/add or remove a backup item/receive sybil resistant airdrops;
  - This intent-based authentication makes sure that **a real human has validated a given operation**
