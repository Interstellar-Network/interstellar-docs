# One-Tap Wallet Backup

The mobile SDK comes with a **new recovery solution** — leveraging Interstellar's next-gen account abstraction to create secure and simple to use backups and recovery logic. Users can **choose between two main backup items** after wallet generation:

### 1. Backup File

Save a [garbled circuit](/authentication/garbled-circuits) Backup File to iCloud, Google Drive, Password Manager, ... or send it to a friend on Whatsapp, Telegram, Singal, ...

- It is **NOT critical if your file is exposed**, as long as you got your phone, or other backup items

### 2. Backup Item

Hold an NFC Item close to your mobile device to register this item as you backup.

- Can be a **day-to-day NFC item**
- If your NFC item is lost, simply remove it from the backup

### Backup Logic

Any user can decide to have:

- **Single item recovery** — 1 NFC item / Secure file
- **Modular multisignature recovery** — 1/2 / 2/3 / 3/5 / ... or any threshhold and item combinations

### Recovery Logic

If your phone has been lost/stolen/damaged, simply recover your wallet on a new mobile device:

- **Tap your NFC Item**/s and/or **upload your Backup File/s** on the new mobile device
