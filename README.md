# Interstellar Docs

Documentation site for [Interstellar Network](https://interstellar.network), built with [Docusaurus](https://docusaurus.io/).

**Live:** [docs.interstellar.network](https://docs.interstellar.network)

## Requirements

- Node.js 20+

## Install

```bash
npm install
```

## Local development

```bash
npm start
```

Starts a local server with live reload.

## Build

```bash
npm run build
```

Output is written to `build/`. Preview with:

```bash
npm run serve
```

## Deployment

Pushes to `main` build and deploy to GitHub Pages via [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
